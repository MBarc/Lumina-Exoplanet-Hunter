ABOUT THE MISSION

Lumina is an independent volunteer project, still in development, that searches NASA's public Kepler data for exoplanet transits. Once the client is released, volunteers' computers will download light curves, run the ExoNet neural network, and report candidates back here. K2 and TESS are planned.
